# Nailgoal legal pages

Privacy policy, support and legal notice for the game Nailgoal, in the 10 languages of the game (en, de, tr, fr, it, id, ru, ja, ko, ar).
Static pages in `docs/` (GitHub Pages: Settings > Pages > Deploy from branch > `main` > `/docs`).
Live address: https://studiosoulway.github.io/nailgoal-legal/

Edit `site.json` (name, address, email, date) or `content.py` (texts), then run `python build.py`.

`app-ads.txt` is NOT here: AdMob reads it from the root of the developer website,
https://studiosoulway.github.io/app-ads.txt (repo `studiosoulway.github.io`), shared by all apps of the account.
